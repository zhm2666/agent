## 1. DQN 的故事背景

### 1.1 Atari 游戏的挑战

2013 年，DeepMind 用**纯图像输入**（210×160 像素）让 AI 玩 Atari 游戏，**在 49 个游戏中有 29 个超过人类专家**。

### 1.2 当时难在哪？

- 状态：图像，10 万维
- 动作：游戏手柄按钮，离散若干个
- 奖励：游戏分数

普通 Q 表根本装不下。但用神经网络 Q 学习，**训练又崩**。

### 1.3 DQN 的突破

加入两个技巧：

1. **经验回放（Replay Buffer）**
2. **目标网络（Target Network）**

之后训练稳定了，深度 RL 才真正起飞。

---

## 2. 为什么神经网络 Q 学习会崩？

### 2.1 三个核心问题

#### 问题 1：数据时序相关

智能体采样是一步一步的，相邻两步状态高度相似。这种数据丢给神经网络，**梯度估计偏差大**（类似 mini-batch 里全是同一类样本）。

#### 问题 2：target 不断漂移

$$
\text{target} = r + \gamma \max Q(s', a')
$$

`Q(s', a')` 来自**同一个网络**。网络权重每步都在更新 → target 也在变 → 这相当于「自己跑自己追自己」。

数学上不收敛。

#### 问题 3：策略和数据相关

智能体发现哪个动作好就多走几步 → 数据越来越偏向某些状态 → 训练不均衡。

### 2.2 DQN 的解药

| 问题 | 解药 |
| --- | --- |
| 数据时序相关 | 经验回放（随机抽样） |
| target 漂移 | 目标网络（冻结） |
| 策略和数据相关 | 经验回放（顺便解决） |

## 3. 关键技巧 1：经验回放（Replay Buffer）

### 3.1 思想

把每一步的 `(s, a, r, s', done)` 存起来。训练时**随机抽一批**。

### 3.2 直观比喻

> 你做模拟题，但题目顺序是按章节来的——相邻题同知识点，复习有偏。
> 经验回放 = **把题目打乱**，随机抽题做。

### 3.3 数学好处

- **打破时序相关性**：抽出的 batch 互相独立
- **数据利用率高**：每条经验可能用多次
- **训练更稳定**：梯度估计更准

---

## 4. 关键技巧 2：目标网络（Target Network）

### 4.1 思想

准备**两个神经网络**：

- `qnet`：主网络，每步都更新
- `qnet_target`：目标网络，每隔 N 步同步一次

算 target 时用 `qnet_target`：

$$
\text{target} = r + \gamma \max_{a} Q_{\text{target}}(s', a)
$$

### 4.2 直观比喻

> 你是学生（`qnet`），目标是追上标准答案（`qnet_target`）。
> 如果标准答案每题都变（你之前答的题），你永远追不上。
> 锁定一份标准答案一阵子，你才追得上。

### 4.3 数学好处

- **target 稳定**：目标网络参数不变
- **收敛保证**：避免「自己追自己」的循环

### 4.4 同步频率

```python
sync_interval = 20  # 每 20 回合同步一次
```

- 太频繁 → 失去意义
- 太慢 → 学得慢

经验值：每 10~100 回合同步一次。

### 5.2 CartPole 任务

一根杆子插在小车上，目标：

- **状态**：4 维向量（小车位置、速度、杆角度、角速度）

- **奖励**：每步 +1

## 6. 第 2 个脚本：replay_buffer.py（实现经验回放）

### 6.1 完整代码

```python
from collections import deque
import random
import numpy as np
import gym


class ReplayBuffer:
    def __init__(self, buffer_size, batch_size):
        self.buffer = deque(maxlen=buffer_size)
        self.batch_size = batch_size

    def add(self, state, action, reward, next_state, done):
        data = (state, action, reward, next_state, done)
        self.buffer.append(data)

    def __len__(self):
        return len(self.buffer)

    def get_batch(self):
        data = random.sample(self.buffer, self.batch_size)

        state      = np.stack([x[0] for x in data])
        action     = np.array([x[1] for x in data])
        reward     = np.array([x[2] for x in data])
        next_state = np.stack([x[3] for x in data])
        done       = np.array([x[4] for x in data]).astype(np.int32)
        return state, action, reward, next_state, done
```

### 6.2 核心方法

#### `add`

把 `(s, a, r, s', done)` 五元组**追加**到缓冲区。`deque(maxlen=buffer_size)` 自动淘汰最旧数据。

#### `get_batch`

1. `random.sample(self.buffer, self.batch_size)`：随机抽 32 条
2. `np.stack`：把 32 个 state 拼成 `(32, 4)` 形状
3. 返回 5 个 `np.ndarray`，每个第一维都是 batch_size

### 6.3 几个常见坑

#### 坑 1：动作和奖励是标量

```python
action = np.array([x[1] for x in data])  # (32,)
reward = np.array([x[2] for x in data])  # (32,)
```

不能 `np.stack`，只能 `np.array`。

#### 坑 2：done 用 int

```python
done = np.array([x[4] for x in data]).astype(np.int32)
```

`bool` 在某些运算时会被吞掉，转 `int32` 显式。

#### 坑 3：buffer_size 选多大？

- 太小：经验复用过少，浪费数据
- 太大：占内存，但更稳定

经验值：10^4 ~ 10^6（任务而定）。

## 7. 第 3 个脚本：dqn.py（完整 DQN）

完整 DQN 实现约 130 行，由 4 个组件构成：

1. **ReplayBuffer**
2. **QNet**（主网络 + 目标网络）
3. **DQNAgent**
4. **训练循环**

### 7.1 网络结构

```python
class QNet(Model):
    def __init__(self, action_size):
        super().__init__()
        self.l1 = L.Linear(128)
        self.l2 = L.Linear(128)
        self.l3 = L.Linear(action_size)

    def forward(self, x):
        x = F.relu(self.l1(x))
        x = F.relu(self.l2(x))
        x = self.l3(x)
        return x
```

3 层全连接，128 隐藏单元，输出每个动作的 Q 值。

### 7.2 智能体

```python
class DQNAgent:
    def __init__(self):
        self.gamma = 0.98
        self.lr = 0.0005
        self.epsilon = 0.1
        self.buffer_size = 10000
        self.batch_size = 32
        self.action_size = 2

        self.replay_buffer = ReplayBuffer(self.buffer_size, self.batch_size)
        self.qnet = QNet(self.action_size)
        self.qnet_target = QNet(self.action_size)         # ← 目标网络
        self.optimizer = optimizers.Adam(self.lr)
        self.optimizer.setup(self.qnet)
```

注意 `self.qnet_target` 是**单独的实例**，初始参数和 `qnet` 一样，但**不参与梯度更新**。

### 7.3 选动作

```python
def get_action(self, state):
    if np.random.rand() < self.epsilon:
        return np.random.choice(self.action_size)
    else:
        state = state[np.newaxis, :]  # ← batch 维
        qs = self.qnet(state)
        return qs.data.argmax()
```

注意 `state[np.newaxis, :]`：把单条 `(4,)` 变成 `(1, 4)`，因为 DeZero 需要 batch 维。

### 7.4 更新（最核心）

```python
def update(self, state, action, reward, next_state, done):
    self.replay_buffer.add(state, action, reward, next_state, done)
    if len(self.replay_buffer) < self.batch_size:
        return                                                # ← 数据不够，暂不更新

    state, action, reward, next_state, done = self.replay_buffer.get_batch()

    # 1) 算当前 Q(s, a)
    qs = self.qnet(state)
    q = qs[np.arange(self.batch_size), action]                 # fancy indexing

    # 2) 算 target（用目标网络）
    next_qs = self.qnet_target(next_state)
    next_q = next_qs.max(axis=1)
    next_q.unchain()                                           # ← 切断梯度
    target = reward + (1 - done) * self.gamma * next_q

    # 3) MSE 损失
    loss = F.mean_squared_error(q, target)

    # 4) 反向传播，更新 qnet
    self.qnet.cleargrads()
    loss.backward()
    self.optimizer.update()
```

### 7.5 同步目标网络

```python
def sync_qnet(self):
    self.qnet_target = copy.deepcopy(self.qnet)
```

`deepcopy` 完整复制参数。

### 7.6 训练主循环

```python
episodes = 300
sync_interval = 20
env = gym.make('CartPole-v0')
agent = DQNAgent()
reward_history = []

for episode in range(episodes):
    state = env.reset()
    done = False
    total_reward = 0

    while not done:
        action = agent.get_action(state)
        next_state, reward, done, info = env.step(action)
        agent.update(state, action, reward, next_state, done)
        state = next_state
        total_reward += reward

    if episode % sync_interval == 0:
        agent.sync_qnet()

    reward_history.append(total_reward)
    if episode % 10 == 0:
        print("episode :{}, total reward : {}".format(episode, total_reward))
```

### 7.7 跑完看效果

```python
plt.plot(reward_history)
plt.show()
```

**典型曲线**：

- 早期：reward 接近 10~30（杆子一推就倒）
- 中期：慢慢升到 50~100
- 后期：稳定在 195+（接近满分）

## 8. 训练过程详解

### 8.1 5 个时间线

```
回合 0:  收集数据 → buffer.add × 200 步 → buffer 满 → 训练
回合 1:  继续收集 → 训练
...
回合 19: 训练
回合 20: 同步目标网络 qnet_target ← qnet
回合 21-39: 训练
回合 40: 同步
...
```

### 8.2 一定要开的监测

| 监测项 | 含义 |
| --- | --- |
| `total_reward` | 每回合总奖励，应单调上升 |
| loss | 应下降但有抖动 |
| buffer 大小 | 早期 < 32 时不训练 |
| `len(buffer)` | 始终 ≤ buffer_size |

### 8.3 失败信号

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| reward 一直 0 | 网络没学 | 调大学习率、查 loss |
| reward 抖动巨大 | 训练不稳 | 减小 lr，增大 batch |
| loss = NaN | 梯度爆炸 | 加梯度裁剪 |
| reward 一直 9.6 | 探索不够 | 增大 ε |

## 9. DQN 的核心代码逐段拆解

### 9.1 一句话总结

> **DQN = 经验回放 + 目标网络 + 神经网络 Q 学习 = 稳定可训练**

### 9.2 完整数据流

```
          [采样一步]
              ↓
   (s, a, r, s', done) → ReplayBuffer
              ↓
   [攒够 32 条] → 抽 batch
              ↓
   ┌──────────────────────────┐
   │ qnet(s) → 算 Q(s, a)    │
   │ qnet_target(s') → 算 max│
   │ target = r + γ·max (done=0)│
   └──────────────────────────┘
              ↓
   loss = (Q(s, a) - target)²
              ↓
   反向传播 → 更新 qnet
              ↓
   每 20 回合同步 qnet_target ← qnet
```

### 9.3 三处 `.unchain()` / 切断梯度

```python
next_q.unchain()  # 在 update 里
```

确保 target 不参与梯度计算（target 是「标准答案」）。

## 10. DQN 之后的改进方向

DQN 是**起点**，不是终点。之后的工作：

| 改进 | 简写 | 核心思想 |
| --- | --- | --- |
| Double DQN | DDQN | 解决 max bias |
| Dueling DQN | - | 把 V 和 A 拆开 |
| Prioritized Replay | - | 重要经验优先采样 |
| Noisy DQN | - | 参数加噪声，代替 ε-greedy |
| Rainbow | - | 集成多种改进 |
| Distributional RL | C51 / QR-DQN | 学 Q 值的分布 |

### 10.1 走向更复杂

- **DQN 系列**：离散动作
- **DDPG / TD3**（连续动作）
- **PPO**（策略梯度,第 9 章）
- **SAC**（最大熵 RL）

## 附录：第 8 章 → 第 9 章的过渡

DQN 学的还是 **Q 值**，策略是 `argmax Q` 派生的。

**第 9 章策略梯度** 换个思路：

> **直接学策略 π(a|s; θ)** —— 一个神经网络，输入状态，输出每个动作的概率。

这就是 **Policy Network / Actor** 路线。

相比 Q 学习：

- **优点**：能处理连续动作；能学到随机策略
- **缺点**：训练方差大

第 9 章会教你两种范式：

- **REINFORCE**：纯策略梯度，简单但方差大
- **Actor-Critic**：策略 + 价值结合，方差小
