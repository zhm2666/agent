## 1. 为什么需要 TD？

### 1.1 MC 的局限

MC 必须等回合结束。**但现实中很多任务没有清晰终止**：

- 实时广告投放：永远在跑
- 自动驾驶：永远没有「结束」状态
- 机器人终身学习：永远在干活

### 1.2 DP 的另一局限

DP 需要完整环境模型。

### 1.3 TD 的优势

**TD（Temporal Difference）** = DP + MC 的混血：

| 维度 | DP | MC | TD |
| --- | --- | --- | --- |
| 需要模型？ | ✅ | ❌ | ❌ |
| 每步更新？ | ✅ | ❌ | ✅ |
| 无偏估计？ | ✅（精确） | ✅ | ❌（有偏） |
| 低方差？ | ❌ | ❌ | ✅ |

**TD 既不需要模型，又能每步更新**——这就是为什么它统治了现代强化学习。

## 2. TD 的核心思想：自举

### 2.1 公式

$$
V(s) \leftarrow V(s) + \alpha \big[ r + \gamma V(s') - V(s) \big]
$$

### 2.2 关键点

- **r + γV(s')** 叫 **TD 目标（TD target）**
- **r + γV(s') - V(s)** 叫 **TD 误差（TD error）**
- **用 V(s') 估计 V(s')** —— 这就是**自举（bootstrapping）**

### 2.3 直观比喻

> 学开车时，你刚转弯进入弯道（前状态 s），看到前方 1 米是弯道出口（后状态 s'），你根据「前方出口在哪」+「现在的速度」估算「我在这段路该多快」。你**不等开完整段路再评估**，而是用下一步的「感觉」来更新现在。

这就是 TD。**每一步都用下一步的估计来更新这一步**。

### 2.4 与 MC 的对比

MC：等回合结束，算真实总奖励 G，更新 V
$$
V(s) \leftarrow V(s) + \alpha \big[ G - V(s) \big]
$$

TD：算一步的奖励 + 下一步的估计，更新 V
$$
V(s) \leftarrow V(s) + \alpha \big[ r + \gamma V(s') - V(s) \big]
$$

**TD 目标有偏（依赖 V(s') 的估计），但方差小。MC 目标无偏，但方差大。**

## 3. 第 1 个脚本：td_eval.py（TD 评估状态价值 V）

### 3.1 完整代码

```python
class TdAgent:
    def __init__(self):
        self.gamma = 0.9
        self.alpha = 0.01          # ← 注意 α 很小（0.01）
        self.action_size = 4
        self.pi = defaultdict(lambda: random_actions)
        self.V = defaultdict(lambda: 0)

    def get_action(self, state):
        action_probs = self.pi[state]
        return np.random.choice(actions, p=probs)

    def eval(self, state, reward, next_state, done):
        next_V = 0 if done else self.V[next_state]
        target = reward + self.gamma * next_V
        self.V[state] += (target - self.V[state]) * self.alpha
```

### 3.2 主循环

```python
for episode in range(1000):
    state = env.reset()
    while True:
        action = agent.get_action(state)
        next_state, reward, done = env.step(action)
        agent.eval(state, reward, next_state, done)  # ← 每步都更新！
        if done:
            break
        state = next_state
```

### 3.3 为什么 α=0.01 这么小？

- TD 每步都更新，**更新频率高**
- 步数多 = 更新次数多
- α 太大 → 估计抖动
- α 太小 → 学得慢

经验值：**TD 用小 α，MC 用大 α**。

### 3.4 跑完看什么？

`env.render_v(agent.V)` 显示 V 图。和 DP、MC 算的结果**长得一样**——但 TD 用了**不同方法、更多回合**、**不需要模型**。

## 4. TD 误差：学习的「差」

```python
target = reward + self.gamma * next_V
self.V[state] += (target - self.V[state]) * self.alpha
```

**TD 误差 δ = target - V(state)**：

- δ > 0：我之前低估了这格的价值，往上调
- δ < 0：我之前高估了，往下压
- δ = 0：完美，该这么定

多个强化学习算法本质上都在**最小化 TD 误差**。

## 5. 第 2 个脚本：sarsa.py（on-policy TD）

### 5.1 名字由来

SARSA 五个字母 = 一次**转移**涉及的五个元素：

$$
S_t, A_t, R_{t+1}, S_{t+1}, A_{t+1}
$$

读作「SARS-A」。

### 5.2 更新公式

$$
Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \alpha \big[ R_{t+1} + \gamma Q(S_{t+1}, A_{t+1}) - Q(S_t, A_t) \big]
$$

**关键**：下一动作 `A_{t+1}` 是用**当前策略 π（ε-greedy）实际采样**出来的。可能不是当前 Q 最大的动作。

### 5.3 完整代码

```python
class SarsaAgent:
    def __init__(self):
        self.gamma = 0.9
        self.alpha = 0.8
        self.epsilon = 0.1
        self.action_size = 4

        random_actions = {0: 0.25, 1: 0.25, 2: 0.25, 3: 0.25}
        self.pi = defaultdict(lambda: random_actions)
        self.Q = defaultdict(lambda: 0)
        self.memory = deque(maxlen=2)        # ← 缓存最近两步

    def get_action(self, state):
        action_probs = self.pi[state]
        return np.random.choice(actions, p=probs)

    def reset(self):
        self.memory.clear()

    def update(self, state, action, reward, done):
        self.memory.append((state, action, reward, done))
        if len(self.memory) < 2:
            return                            # ← 还不到两步先返回

        state, action, reward, done = self.memory[0]
        next_state, next_action, _, _ = self.memory[1]
        next_q = 0 if done else self.Q[next_state, next_action]   # ← 用实际 next_action

        target = reward + self.gamma * next_q
        self.Q[state, action] += (target - self.Q[state, action]) * self.alpha
        self.pi[state] = greedy_probs(self.Q, state, self.epsilon)
```

### 5.4 为什么 deque(maxlen=2)？

要算 `Q(S_{t+1}, A_{t+1})`，需要等到下一步采到动作 `A_{t+1}`。所以缓存最近两步「凑齐五元组」。

### 5.5 主循环

```python
for episode in range(10000):
    state = env.reset()
    agent.reset()
    while True:
        action = agent.get_action(state)
        next_state, reward, done = env.step(action)
        agent.update(state, action, reward, done)   # ← 把 A_{t+1} 存到 memory
        if done:
            agent.update(next_state, None, None, None)  # ← 末次凑数，下一步 Q=0
            break
        state = next_state
```

### 5.6 关键名字：on-policy

SARSA 是 **on-policy（在策略）**：

> 「**用策略 π 采的数据，学策略 π 自己**」。

它学到的策略价值是「**带探索抖动**」的——**保守**。

## 6. 第 3 个脚本：q_learning.py（off-policy TD）

### 6.1 更新公式

$$
Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \alpha \big[ R_{t+1} + \gamma \max_{a} Q(S_{t+1}, a) - Q(S_t, A_t) \big]
$$

**关键差**：用 `max_a Q(S_{t+1}, a)`，**完全不管** ε-greedy 实际会走哪条。

### 6.2 完整代码

```python
class QLearningAgent:
    def __init__(self):
        self.gamma = 0.9
        self.alpha = 0.8
        self.epsilon = 0.1
        self.action_size = 4

        random_actions = {0: 0.25, 1: 0.25, 2: 0.25, 3: 0.25}
        self.pi = defaultdict(lambda: random_actions)   # ← 目标策略（ε=0）
        self.b  = defaultdict(lambda: random_actions)   # ← 行为策略（ε-greedy）
        self.Q = defaultdict(lambda: 0)

    def get_action(self, state):
        action_probs = self.b[state]   # ← 用 b 采样
        return np.random.choice(actions, p=probs)

    def update(self, state, action, reward, next_state, done):
        if done:
            next_q_max = 0
        else:
            next_qs = [self.Q[next_state, a] for a in range(self.action_size)]
            next_q_max = max(next_qs)                  # ← 不在乎实际走的动作

        target = reward + self.gamma * next_q_max
        self.Q[state, action] += (target - self.Q[state, action]) * self.alpha

        self.pi[state] = greedy_probs(self.Q, state, epsilon=0)    # ← π 纯贪心
        self.b[state]  = greedy_probs(self.Q, state, self.epsilon) # ← b 带探索
```

### 6.3 关键区别：不需要 deque

SARSA 必须等 `A_{t+1}` 才能算 → 需要缓存。
Q 学习只依赖 `state`，不依赖 `A_{t+1}` → 单步更新。

### 6.4 关键名字：off-policy

Q 学习是 **off-policy（离策略）**：

> 「**用一个策略 b 采数据，学另一个策略 π 的价值**」。

它学到的策略价值是「**纯贪心最优**」的——**激进**。

### 6.5 主循环

```python
while True:
    action = agent.get_action(state)
    next_state, reward, done = env.step(action)
    agent.update(state, action, reward, next_state, done)   # ← 立即更新
    if done:
        break
    state = next_state
```

注意 update 收 `next_state`——Q 学习是**单步更新**。

## 7. 第 4 个脚本：q_learning_simple.py（极简版 Q 学习）

### 7.1 简化在哪？

把 `pi` 和 `b` 合并：行为策略与目标策略都在 `get_action` 里现场算。

```python
class QLearningAgent:
    def __init__(self):
        self.gamma = 0.9
        self.alpha = 0.8
        self.epsilon = 0.1
        self.action_size = 4
        self.Q = defaultdict(lambda: 0)

    def get_action(self, state):
        if np.random.rand() < self.epsilon:
            return np.random.choice(self.action_size)
        else:
            qs = [self.Q[state, a] for a in range(self.action_size)]
            return np.argmax(qs)

    def update(self, state, action, reward, next_state, done):
        if done:
            next_q_max = 0
        else:
            next_qs = [self.Q[next_state, a] for a in range(self.action_size)]
            next_q_max = max(next_qs)
        target = reward + self.gamma * next_q_max
        self.Q[state, action] += (target - self.Q[state, action]) * self.alpha
```

### 7.2 教学意义

代码更短，**核心只剩 Q 更新公式**。让你专注算法本质，不被「策略定义」分散注意力。

生产环境一般用 `q_learning.py` 的版本（显式分 pi 和 b，代码更清晰）。

## 8. 第 5 个脚本：sarsa_off_policy.py（off-policy SARSA）

### 8.1 动机

SARSA 本身是 on-policy 的。「off-policy SARSA」让它像 Q 学习那样——**用 b 采样，学 π**。

### 8.2 关键代码

```python
class SarsaOffPolicyAgent:
    def update(self, state, action, reward, done):
        self.memory.append((state, action, reward, done))
        if len(self.memory) < 2:
            return

        state, action, reward, done = self.memory[0]
        next_state, next_action, _, _ = self.memory[1]

        if done:
            next_q = 0
            rho = 1
        else:
            next_q = self.Q[next_state, next_action]
            rho = self.pi[next_state][next_action] / self.b[next_state][next_action]   # ← 重要性权重

        target = rho * (reward + self.gamma * next_q)
        self.Q[state, action] += (target - self.Q[state, action]) * self.alpha

        self.pi[state] = greedy_probs(self.Q, state, 0)
        self.b[state] = greedy_probs(self.Q, state, self.epsilon)
```

### 8.3 重要性权重 ρ

$$
\rho = \frac{\pi(A_{t+1}|S_{t+1})}{b(A_{t+1}|S_{t+1})}
$$

含义：

- 如果 b 不太可能做这个动作（b 概率小），但 π 经常做（π 概率大）→ ρ 大 → 这次样本对学 π 很有价值，放大
- 反之 ρ 小 → 缩小

### 8.4 与 Q 学习对比

| 维度 | Q 学习 | off-policy SARSA |
| --- | --- | --- |
| 目标中的下一动作 | max | 实际 next_action |
| 是否需要重要性权重 | ❌ | ✅ |
| 方差 | 低 | 高 |
| 实现复杂度 | 简单 | 复杂 |

实践中 **Q 学习更常用**，off-policy SARSA 较少使用。

## 9. SARSA vs Q 学习：核心对比

### 9.1 公式对比（唯一区别已加粗）

SARSA：
$$
Q(s,a) \leftarrow Q(s,a) + \alpha \big[ r + \gamma \mathbf{Q(s', a')} - Q(s,a) \big]
$$
（其中 `a'` 是 ε-greedy 实际采到的）

Q 学习：
$$
Q(s,a) \leftarrow Q(s,a) + \alpha \big[ r + \gamma \mathbf{\max_{a'} Q(s', a')} - Q(s,a) \big]
$$
（其中 `a'` 是 Q 值最大的那个）

**就一个字母的差别：Q 是 `Q(s', a')`，SARSA 也是 `Q(s', a')`，但 SARSA 的 `a'` 是实际采样，Q 学习的 `a'` 是假设最优。**

### 9.2 全方位对比表

| 维度 | SARSA | Q 学习 |
| --- | --- | --- |
| 类型 | on-policy | off-policy |
| 更新公式用实际下一动作 | ✅ | ❌（用 max） |
| 学习的策略 | 带探索的策略 | 纯贪心最优策略 |
| 代码量 | 较多（要 deque） | 较少 |
| 风险环境表现 | 保守（绕远） | 激进（贴边） |
| 收敛速度 | 较慢（噪声大） | 较快 |
| 适用场景 | 真实系统、有探索成本 | 仿真、可离线训练 |
| 项目对应文件 | `ch06/sarsa.py` | `ch06/q_learning.py` |

### 9.3 一个比喻

**SARSA = 谨慎的小狐狸**：考虑「万一我手抖呢」，所以绕开悬崖。

**Q 学习 = 乐观的小狐狸**：假设自己从不抖，按最优路径走。

## 10. 在 GridWorld 上的直观结果

### 10.1 网格世界

```
[[ 0. ,  0. ,  0. ,  1.0],   ← (0,3) 目标 +1
 [ 0. , None,  0. , -1.0],   ← (1,1) 墙，(1,3) 陷阱 -1
 [ 0. ,  0. ,  0. ,  0. ]]   ← (2,0) 起点
```

### 10.2 跑出来的策略箭头

**Q 学习**（激进）：
```
→  →  →  ★      （目标）
↑  墙  →  ✗      （陷阱）
↑  →  →  ↑
```
**直接从陷阱下方钻过去**，因为它假定自己会走最优。

**SARSA**（保守）：
```
→  →  →  ★
↑  墙  ↑  ✗      ← 注意这里改方向了
↑  →  →  ↑
```
**绕开陷阱列**，因为它考虑了「万一走错就掉下去」。


## 11. Q 学习的「最大偏差」问题

### 11.1 偏差来源

在 Q 学习里：

$$
\text{TD 目标} = r + \gamma \max_a Q(s', a)
$$

`max` 会**偏向于选中那些被高估的动作**。即使所有 Q 估计都是**无偏**的（正负噪声都有），取 max 后也「**倾向于最大**」。

### 11.2 后果

- 训练后期 Q 值会**整体偏高**
- 严重影响策略质量

### 11.3 解决方案

- **Double Q 学习**：用两个 Q 表交替选/评估
- **在 DQN 中用 target network**（第 8 章）
- **重要性采样权重**（ch06 的 off-policy SARSA）

### 11.4 与 SARSA 的对比

SARSA 没 max，没有这个偏差；但它有别的问题（学最优策略慢）。

第 6 章的 Q 表是 `dict[(state, action)] → float`。
