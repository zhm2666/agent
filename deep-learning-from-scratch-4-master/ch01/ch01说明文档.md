## 1. 什么是老虎机问题

想象你走进赌场，看到一排老虎机（俗称「老虎」），每台机器的中奖概率不一样：

```
机器1号：每拉一次有 30% 概率吐 1 元
机器2号：每拉一次有 50% 概率吐 1 元
机器3号：每拉一次有 70% 概率吐 1 元
... （共 10 台）
```

你**不知道**谁高谁低，你可以一台一台拉，但每次拉都需要一个币。怎么用 1000 次拉杆赚最多的钱？

这就是 **k-armed bandit**（k 臂老虎机）问题——强化学习最简化的版本。

---

## 2. 用大白话讲：老虎机为什么不是普通选择题

普通数学题给你 4 个选项，标好了 ABCD，你只需要选一个。

老虎机问题**没有标准答案**告诉你——你只能**试**。而且每台机器的回报是**随机**的：就算 3 号机器中奖率 70%，你也可能连拉 10 次都不中。

所以智能体面对的核心矛盾是：

> **我到底应该继续拉我已经觉得不错的机器（利用），还是去试试还没拉过几次的机器（探索）？**

这就是著名的 **Exploration-Exploitation Dilemma（探索-利用困境）**。

## 3. 第 1 个脚本：avg.py（求平均的 Hello World）

```python
import numpy as np

np.random.seed(0)
rewards = []

for n in range(1, 11):
    reward = np.random.rand()
    rewards.append(reward)
    Q = sum(rewards) / n
    print(f"第 {n} 次：奖励 {reward:.3f}，平均 Q = {Q:.3f}")
```

这 11 行代码就做了一件事：**演示如何增量地求平均值**。

第 n 次的平均值：

$$
Q_n = \frac{r_1 + r_2 + \dots + r_n}{n}
$$

把它「增量」改写：

$$
Q_n = Q_{n-1} + \frac{1}{n}(r_n - Q_{n-1})
$$

含义：**新平均 = 旧平均 + (1/n) × (新观测 - 旧平均)**

这就是后面所有 Q 表更新的**原型公式**。把这个公式记在脑子里，整本书的更新思路你都懂了一大半。

## 4. 第 2 个脚本：bandit.py（ε-greedy 登场）

完整代码（`ch01/bandit.py`）有两个类：`Bandit`（环境）和 `Agent`（智能体）。

### 4.1 Bandit 类：环境

```python
class Bandit:
    def __init__(self, arms=10):
        self.rates = np.random.rand(arms)  # 10 台机器的真实中奖率，随机生成

    def play(self, arm):
        rate = self.rates[arm]
        if rate > np.random.rand():   # 生成 0~1 随机数，小于 rate 就中奖
            return 1                  # 吐 1 元
        else:
            return 0                  # 不吐
```

注意：

- `self.rates` 是**真实**中奖率，**智能体不知道**（这是重点）。
- `play(arm)` 不是返回 `rate`，而是按 `rate` 概率**抽样**出 0 或 1。
- 这就是环境给智能体的**奖励噪声**。

### 4.2 Agent 类：智能体

```python
class Agent:
    def __init__(self, epsilon, action_size=10):
        self.epsilon = epsilon
        self.Qs = np.zeros(action_size)  # 智能体维护的「估计中奖率」
        self.ns = np.zeros(action_size)  # 每台机器被拉了几次

    def update(self, action, reward):
        self.ns[action] += 1
        self.Qs[action] += (reward - self.Qs[action]) / self.ns[action]
        #                           ↑ 这就是增量平均公式！

    def get_action(self):
        if np.random.rand() < self.epsilon:    # 概率 ε 探索
            return np.random.randint(0, len(self.Qs))
        return np.argmax(self.Qs)              # 否则选估计值最高的
```

### 4.3 主循环

```python
bandit = Bandit()
agent = Agent(epsilon=0.1)   # 10% 概率探索
total_reward = 0
total_rewards = []

for step in range(1000):
    action = agent.get_action()             # 1) 选机器
    reward = bandit.play(action)            # 2) 拉一把
    agent.update(action, reward)            # 3) 更新估计
    total_reward += reward
    total_rewards.append(total_reward)
```

**重要参数 `epsilon = 0.1`**：

- 10% 概率随便抽（探索）
- 90% 概率选估计值最高的（利用）

最后画两张图：
- **Total Reward 曲线**：一步一步累加的总奖励
- **Rates 曲线**：平均奖励 = total_reward / (step+1)，会**逐渐上升**并接近**最优机器的真实中奖率**

### 4.4 直观理解

跑 1000 步后，曲线会**抬头**：
- 早期：乱抽，命中率低
- 中期：智能体开始识别出哪几台机器不错
- 后期：大部分时间在拉那台最好的机器，平均奖励逼近最优

## 5. 第 3 个脚本：bandit_avg.py（把求平均写得更直白）

这个脚本和 `bandit.py` 几乎一样，只是把更新公式写成 `+= (reward - Q) / ns[action]` 这种**除以 n** 的形式（也就是**样本平均**）。

数学上：

$$
Q_n(a) = Q_{n-1}(a) + \frac{1}{n}(r_n - Q_{n-1}(a))
$$

含义：每来一次新观测，**新估计 = 旧估计 + 1/n × 误差**。n 越大，修正量越小——因为观测多到一定程度，老估计已经够准了。

特征：

- **优点**：随 n→∞，Q 收敛到真实中奖率。
- **缺点**：在**非平稳**环境（下一节）里反应慢。

## 6. 第 4 个脚本：non_stationary.py（环境在变！）

### 6.1 引入「非平稳」老虎机

```python
class NonStatBandit:
    def play(self, arm):
        rate = self.rates[arm]
        self.rates += 0.1 * np.random.randn(self.arms)  # 每次 play 后所有机器的中奖率都加点随机扰动
        if rate > np.random.rand():
            return 1
        else:
            return 0
```

每拉一次，**所有 10 台机器的中奖率都加一点正态噪声**。这意味着：「昨天最好的机器，今天不一定是最好的」。

### 6.2 两个 Agent 对比

```python
class AlphaAgent:
    def update(self, action, reward):
        self.Qs[action] += (reward - self.Qs[action]) * self.alpha
        #                            ↑ 用固定 α 代替 1/n
```

把 `1/n` 换成**常数 α**（比如 0.8）：

$$
Q_n(a) = Q_{n-1}(a) + \alpha(r_n - Q_{n-1}(a))
$$

### 6.3 比较 200 轮、每轮 1000 步

```python
runs = 200
steps = 1000
agent_types = ['sample average', 'alpha const update']

for agent_type in agent_types:
    all_rates = np.zeros((runs, steps))
    for run in range(runs):
        if agent_type == 'sample average':
            agent = Agent(epsilon=0.1)
        else:
            agent = AlphaAgent(epsilon=0.1, alpha=0.8)
        # ... 跑 1000 步 ...
        all_rates[run] = rates
    avg_rates = np.average(all_rates, axis=0)
    results[agent_type] = avg_rates
```

### 6.4 实验结果

画出的图会非常清楚地展示：

- **sample average**（蓝色）：早期上升快，但**到后面平了**，因为 1/n 越来越小，对新变化反应慢。
- **alpha const update**（橙色）：始终保持一定的上升趋势，因为 α=0.8 永远给最新观测 80% 的权重。

> **关键结论：在非平稳环境中，恒定 α > 样本平均。**

### 6.5 直觉解释

假设老虎机中奖率突然变化 0.1：

- 样本平均：如果 n 已经 1000，要等 1000 次才能把 1/n 累积调整到接受新值。
- 恒定 α：每次都直接把误差的 80% 加进 Q，**一步就能感受到环境变化**。

代价是：恒定 α 永远不会「收敛」，所以估计会**永远抖动**。但因为噪声只是小幅扰动，trade-off 划算。

## 7. 核心概念总结：增量平均 vs 恒定 α

| 维度 | 样本平均（`1/n`） | 恒定 α |
| --- | --- | --- |
| 更新公式 | `Q += (r - Q) / n` | `Q += (r - Q) * α` |
| 对新数据的权重 | `1/n`，越来越小 | 永远是 α |
| 适用环境 | **平稳**（中奖率不变） | **非平稳**（中奖率变化） |
| 收敛性 | **收敛**到真实中奖率 | 永远不收敛，但能跟踪变化 |
| 调参难度 | 无需调 α | 需要调 α ∈ (0,1) |

### 7.1 把这两个推广到任意 RL 算法

所有强化学习的更新公式都长得像：

$$
\text{新估计} = \text{旧估计} + \alpha \cdot (\text{新目标} - \text{旧估计})
$$

第 1 章教我们的 `α` 和「目标-估计」这个**减法**，正是后面所有算法的核心。

## 附：第 1 章 → 第 2 章的过渡

第 1 章**没有状态**：不管你拉了几次，下一次「选哪台机器」都是独立决策。

但真实的强化学习有 **状态**（state）：你今天的身体状态、你现在的位置、你过去说了什么，都会影响下一步选什么。

从第 2 章开始，书籍会引入这些概念。**但第 1 章的「增量更新 + ε-greedy + 探索利用」三大心法，会贯穿整本书**。把这一章吃透，后面的学习会顺很多。
