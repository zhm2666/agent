# 第 1 章：多臂老虎机 — 学习文档

| 文件 | 说明 |
| --- | --- |

## 关键收获

- **探索 vs 利用**是强化学习的核心矛盾
- **增量更新公式** `Q += α * (目标 - Q)` 贯穿全书
- 样本平均 `1/n` 与恒定 α 在平稳/非平稳环境各有优劣
