# 第 5 章：蒙特卡洛法 —— 走完一整局再回头学习

> 第 4 章的**动态规划**需要完整的转移模型 `P(s'|s,a)`，但现实往往没有。
>
> 第 5 章教你一个**只需要经验**的方法：**蒙特卡洛（Monte Carlo, MC）**。
>
> 核心思想：**让智能体真的去玩，跑完一整局（episode），然后回头算每个状态/动作实际带来了多少奖励**。

## 1. 为什么需要蒙特卡洛？

DP 的核心难题是「**需要完整环境模型**」。可现实中：

- 走迷宫？你不知道下一秒会被风吹到哪
- 下棋？对手怎么应子你猜不到
- 自动驾驶？别的车怎么开你控制不了

但**这些场景你都可以玩**，能**真的去跑一局**。

MC 就是：**不靠模型，靠真实样本**。

和 DP 的对比：

| 维度 | DP | MC |
| --- | --- | --- |
| 需要模型？ | ✅ 要 | ❌ 不要 |
| 一步能不能更新？ | ✅ 能 | ❌ 必须等回合结束 |
| 适合场景 | 模型已知的小问题 | 黑箱环境的大问题 |
| 估计方法 | 期望的计算 | 样本的平均 |

## 2. 核心概念：回报 G_t

**回报** = 从时刻 t 开始到回合结束的所有奖励的**折扣加和**：

$$
G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \dots
$$

示例：一回合轨迹

```
t=0: s0 → a0 → r1=0 → s1 → a1 → r2=1 → done
```

$$
G_0 = r_1 + \gamma r_2 = 0 + 0.9 \cdot 1 = 0.9
$$

如果走得更长：

```
s0 → r1=0 → s1 → r2=0 → s2 → r3=1 → done
```

$$
G_0 = 0 + 0.9 \cdot 0 + 0.9^2 \cdot 1 = 0.81
$$

回头用这个 G 更新 Q。

## 3. 第 1 个脚本：dice.py（MC 的极简原型）

```python
def sample(dices=2):
    x = 0
    for _ in range(dices):
        x += np.random.choice([1, 2, 3, 4, 5, 6])
    return x

trial = 1000
V, n = 0, 0

for _ in range(trial):
    s = sample()
    n += 1
    V += (s - V) / n        # ← 增量平均！
    print(V)
```

### 3.1 在干什么？

- 摇两颗骰子，把点数和记为 s
- 用**增量平均**估计 s 的数学期望

### 3.2 数学期望

理论值两颗骰子点数和 = 7（均匀分布 2~12，平均 7）。

### 3.3 输出样子

```
7.0
7.5
7.0
6.667
6.8
...
```

跑 1000 次后，V 会收敛到 7 附近。

### 3.4 教学意义

这是**最纯粹的 MC**：用随机样本去**估计一个我不知道的期望值**。整个 MC 强化学习就是把它套到 `E[回报]` 上。

## 4. 第 2 个脚本：importance_sampling.py（重要性采样）

### 4.1 场景与动机

我们需要算某分布 π 下的期望 `E_π[x]`。但**采样是按另一分布 b 进行的**（b 比较好采）。

**重要性采样（Importance Sampling）** 用「权重」把 b 的样本折算回 π 的期望。

### 4.2 代码

```python
x = np.array([1, 2, 3])
pi = np.array([0.1, 0.1, 0.8])

# 直接期望
e = np.sum(x * pi)
print('E_pi[x]', e)  # 0.1*1 + 0.1*2 + 0.8*3 = 2.7

# 普通 MC：按 π 抽样
n = 100
samples = []
for _ in range(n):
    s = np.random.choice(x, p=pi)
    samples.append(s)
print('MC: {:.2f} (var: {:.2f})'.format(np.mean(samples), np.var(samples)))

# 重要性采样：按 b 抽样，但乘 π[i]/b[i]
b = np.array([0.2, 0.2, 0.6])
samples = []
for _ in range(n):
    i = np.random.choice(np.arange(len(b)), p=b)
    s = x[i]
    rho = pi[i] / b[i]                  # ← 重要性权重
    samples.append(rho * s)
print('IS: {:.2f} (var: {:.2f})'.format(np.mean(samples), np.var(samples)))
```

### 4.3 直观理解

- b 把更多概率给 0（小值），少给 2（大值）
- 但我们关心 π 给 2 的概率 0.8，是 0.1 的 8 倍
- 所以当 b 采到 2 时，权重 `ρ = 0.8/0.6 ≈ 1.33`，把样本**放大**
- 当 b 采到 0 时，权重 `ρ = 0.1/0.2 = 0.5`，把样本**缩小**

这样最后平均出来还是 `E_π[x] = 2.7`。

### 4.4 为什么有「方差」？

如果 b 的支撑集和 π 差太多，ρ 会忽大忽小，方差爆炸。**好的重要性采样 = b 接近 π**。

### 4.5 在 RL 中的用途

MC 离策略（off-policy）算法就要用重要性采样：
- 行为策略 b（带探索）收集数据
- 目标策略 π（贪心）是我们想学的
- 用 `ρ = π(a|s)/b(a|s)` 修正每一个样本

## 5. 第 3 个脚本：mc_eval.py（MC 策略评估）

### 5.1 目标

给定策略 π（这里用随机策略），只算每个状态的价值 V。

### 5.2 关键代码

```python
class RandomAgent:
    def add(self, state, action, reward):
        self.memory.append((state, action, reward))

    def reset(self):
        self.memory.clear()

    def eval(self):
        G = 0
        for data in reversed(self.memory):  # ← 从尾巴往头算
            state, action, reward = data
            G = self.gamma * G + reward
            self.cnts[state] += 1
            self.V[state] += (G - self.V[state]) / self.cnts[state]
```

### 5.3 倒着算 G 的妙处

按定义：

$$
G_t = r_{t+1} + \gamma r_{t+2} + \gamma^2 r_{t+3} + \dots
$$

倒着递推：

$$
G_t = r_{t+1} + \gamma G_{t+1}
$$

代码里 `G = γ·G + reward` 就是这个递推。

### 5.4 增量更新

```python
self.V[state] += (G - self.V[state]) / self.cnts[state]
```

**和老虎机里 1/n 增量平均一模一样**——MC 强化学习 = 老虎机 + 状态。

### 5.5 跑完

```python
total_reward = 0
for step in range(1000):
    action = agent.get_action(state)
    next_state, reward, done = env.step(action)
    agent.add(state, action, reward)
    if done:
        agent.eval()  # ← 回合结束才更新！
        break
    state = next_state
```

跑 1000 个回合，V 表会越来越准，最终和 DP 算的 V 几乎一致。

## 6. 第 4 个脚本：mc_control.py（MC 控制 + ε-greedy）

### 6.1 目标

不只评估已有策略，还**改进策略**让它越来越好。

### 6.2 核心思想

策略迭代的 MC 版：
1. 用当前策略 π 跑一回合
2. 算出每个 (state, action) 的实际回报 G
3. 更新 Q 表
4. 基于 Q 表更新策略 π（ε-greedy）

### 6.3 关键代码

```python
class McAgent:
    def __init__(self):
        self.gamma = 0.9
        self.epsilon = 0.1
        self.alpha = 0.1             # ← 用恒定 α 而非 1/n
        self.pi = defaultdict(lambda: random_actions)
        self.Q = defaultdict(lambda: 0)
        self.memory = []

    def update(self):
        G = 0
        for data in reversed(self.memory):
            state, action, reward = data
            G = self.gamma * G + reward
            key = (state, action)
            self.Q[key] += (G - self.Q[key]) * self.alpha   # ← 恒定 α
            self.pi[state] = greedy_probs(self.Q, state, self.epsilon)
```

### 6.4 为什么用 α 而不是 1/n？

- MC 每回合可能多次访问同一个 `(s,a)`，1/n 累计会很慢
- 恒定 α 始终对新数据有合理响应
- 数学上：如果每回合最多访问一次 `(s,a)`，两种等价

### 6.5 完整主循环

```python
for episode in range(10000):
    state = env.reset()
    agent.reset()
    while True:
        action = agent.get_action(state)
        next_state, reward, done = env.step(action)
        agent.add(state, action, reward)
        if done:
            agent.update()  # 回合结束才更新
            break
        state = next_state
env.render_q(agent.Q)
```

跑 10000 回合，Q 表会收敛到最优 Q\*。

## 7. 第 5 个脚本：mc_control_offpolicy.py（MC 离策略）

### 7.1 什么是「on-policy / off-policy」？

- **on-policy（在策略）**：用一个策略去采样、学策略
- **off-policy（离策略）**：用一个策略（行为策略 b，比如带探索）去采样，学另一个策略（目标策略 π，比如纯贪心）

### 7.2 关键代码

```python
class McOffPolicyAgent:
    def update(self):
        G = 0
        rho = 1
        for data in reversed(self.memory):
            state, action, reward = data
            key = (state, action)
            G = self.gamma * rho * G + reward   # ← G 乘上 ρ
            self.Q[key] += (G - self.Q[key]) * self.alpha
            rho *= self.pi[state][action] / self.b[state][action]   # ← 累积 ρ
            self.pi[state] = greedy_probs(self.Q, state, epsilon=0)
            self.b[state] = greedy_probs(self.Q, state, self.epsilon)
```

### 7.3 累积重要性权重

$$
\rho_{t:t+n-1} = \prod_{k=t}^{t+n-1} \frac{\pi(A_k | S_k)}{b(A_k | S_k)}
$$

**倒序累积**：每一步把当前步的 ρ 乘到累积 ρ 上。

### 7.4 on-policy vs off-policy 在 MC 上的差异

| 维度 | on-policy MC | off-policy MC |
| --- | --- | --- |
| 行为策略 | π（带探索） | b（带探索） |
| 目标策略 | π（同上） | π（纯贪心） |
| 学习目标 | 带探索的最优策略 | 纯贪心的最优策略 |
| 数据使用 | 直接 | 加重要性权重 |
| 稳定性 | 较稳 | 方差可能大 |

### 7.5 直观比喻

**on-policy**：你自己写完作业、自己批改、自己订正。

**off-policy**：你看同学的标准答案（target policy），用你自己的笔记（behavior policy）作为参考，但要修正笔记和答案的差异（importance sampling）。

## 8. MC 的优点、缺点与适用场景

### 8.1 优点

- ✅ **不需要环境模型**
- ✅ **概念简单**：跑完一局回过头算就行
- ✅ **无偏估计**：用真实样本估计期望
- ✅ **对环境结构无要求**：离散连续都行

### 8.2 缺点

- ❌ **必须等回合结束**：如果任务跑 24 小时，24 小时后才更新
- ❌ **高方差**：单条轨迹噪声大
- ❌ **不适合连续任务**：无终止状态就没法算 G

### 8.3 适用场景

- 游戏（每局可结束）
- 棋类（每盘可结束）
- 任何「有清晰回合起止」的任务

### 8.4 不能用 MC 的场景

- 机器人终身学习（没有「结束」）
- 股票交易（一直在进行）

→ 后面的 **TD（时间差分）** 解决这些问题。

## 附：第 5 章 → 第 6 章的过渡

MC 的核心限制是「必须等回合结束」。

**第 6 章的 TD（Temporal Difference，时间差分）打破了这一限制**：每走一步就更新一次。这就是大名鼎鼎的 **SARSA** 和 **Q 学习**。

TD 是 DP 和 MC 的「混血」：
- 用了 DP 的「Bellman 思想」（看下一步）
- 用了 MC 的「样本估计」（不用模型）

数学上，TD 是 **自举（bootstrapping）**：用**自己的估计**去更新**自己的估计**。
