## 2. 相关配置

### 2.1 平台配置：`config/weibo_config.py`

微博平台的专有配置定义在这里：

```python
WEIBO_SEARCH_TYPE = "popular"
WEIBO_SPECIFIED_ID_LIST = [
    "4982041758140155",
]
WEIBO_CREATOR_ID_LIST = [
    "5533390220",
]
```

说明：

- `WEIBO_SEARCH_TYPE` 决定微博搜索类型，可选值定义在 `field.py`。
- `WEIBO_SPECIFIED_ID_LIST` 用于 `detail` 模式：直接爬指定微博。
- `WEIBO_CREATOR_ID_LIST` 用于 `creator` 模式：直接爬指定博主主页内容。

### 2.2 基础配置：`config/base_config.py`

微博模块依赖 `base_config.py` 中的全局运行参数，例如：

```python
PLATFORM = "wb"
KEYWORDS = "..."
LOGIN_TYPE = "qrcode"
CRAWLER_TYPE = "search"
SAVE_DATA_OPTION = "db"
CRAWLER_MAX_NOTES_COUNT = 50
ENABLE_GET_COMMENTS = True
CRAWLER_MAX_COMMENTS_COUNT_SINGLENOTES = 20
HEADLESS = True
```

`PlatformCrawler` 会在运行前把这里的关键值替换成微博实际任务所需参数。

### 2.3 搜索类型：`field.py`

```python
class SearchType(Enum):
    DEFAULT = "1"
    REAL_TIME = "61"
    POPULAR = "60"
    VIDEO = "64"
```

搜索类型会转成 `containerid` 的一部分，拼到微博搜索 API 参数里。

## 3. 微博爬虫入口：`core.py`

`WeiboCrawler` 是微博平台的总控类，继承自 `base/base_crawler.py` 中的 `AbstractCrawler`。

核心职责：

1. 启动浏览器；
2. 检查登录状态；
3. 按 `CRAWLER_TYPE` 分发任务；
4. 协调搜索、详情、评论、图片、创作者主页等流程。

```python
class WeiboCrawler(AbstractCrawler):
    context_page: Page
    wb_client: WeiboClient
    browser_context: BrowserContext
    cdp_manager: Optional[CDPBrowserManager]
```

### 3.1 启动与登录

`start()` 方法完成以下动作：

```python
async def start(self):
    # 1. 可选：创建代理池
    # 2. 启动浏览器，支持标准模式或 CDP 模式
    # 3. 打开手机版微博首页
    # 4. 创建 API 客户端 WeiboClient
    # 5. 调用 pong 检查登录态
    # 6. 若未登录，执行 WeiboLogin.begin()
    # 7. 登录成功后刷新移动端首页并更新 cookie
    # 8. 按 CRAWLER_TYPE 分发任务
```

浏览器启动方式有两种：

- **标准模式**：Playwright 启动 Chromium，加载 `stealth.min.js` 降低被识别概率。
- **CDP 模式**：连接已有浏览器实例，便于调试和复用登录环境。

```python
async def launch_browser(self, chromium, playwright_proxy, user_agent, headless=True):
    if config.SAVE_LOGIN_STATE:
        user_data_dir = os.path.join(
            os.getcwd(), "browser_data", config.USER_DATA_DIR % config.PLATFORM
        )
        browser_context = await chromium.launch_persistent_context(
            user_data_dir=user_data_dir,
            headless=headless,
            proxy=playwright_proxy,
            viewport={"width": 1920, "height": 1080},
            user_agent=user_agent,
        )
        return browser_context
    else:
        browser = await chromium.launch(headless=headless, proxy=playwright_proxy)
        browser_context = await browser.new_context(
            viewport={"width": 1920, "height": 1080},
            user_agent=user_agent,
        )
        return browser_context
```

登录态成功保存到 `browser_data/` 后，后续运行可直接复用。

### 3.2 搜索模式

当 `CRAWLER_TYPE == "search"` 时，进入 `search()`：

```python
async def search(self):
    weibo_limit_count = 10
    if config.CRAWLER_MAX_NOTES_COUNT < weibo_limit_count:
        config.CRAWLER_MAX_NOTES_COUNT = weibo_limit_count
    start_page = config.START_PAGE

    # 根据 WEIBO_SEARCH_TYPE 选择搜索类型
    if config.WEIBO_SEARCH_TYPE == "default":
        search_type = SearchType.DEFAULT
    elif config.WEIBO_SEARCH_TYPE == "real_time":
        search_type = SearchType.REAL_TIME
    elif config.WEIBO_SEARCH_TYPE == "popular":
        search_type = SearchType.POPULAR
    elif config.WEIBO_SEARCH_TYPE == "video":
        search_type = SearchType.VIDEO

    # 遍历每个关键词
    for keyword in config.KEYWORDS.split(","):
        page = 1
        while (page - start_page + 1) * weibo_limit_count <= config.CRAWLER_MAX_NOTES_COUNT:
            search_res = await self.wb_client.get_note_by_keyword(
                keyword=keyword, page=page, search_type=search_type
            )
            note_list = filter_search_result_card(search_res.get("cards"))
            for note_item in note_list:
                mblog = note_item.get("mblog")
                if mblog:
                    note_id_list.append(mblog.get("id"))
                    await weibo_store.update_weibo_note(note_item)
                    await self.get_note_images(mblog)

            page += 1
            await asyncio.sleep(config.CRAWLER_MAX_SLEEP_SEC)
            await self.batch_get_notes_comments(note_id_list)
```

搜索流程要点：

- 微博搜索接口每页固定返回 10 条结果；
- 通过 `page` 和最大爬取数量控制翻页；
- 每个 `cards` 列表先经过 `filter_search_result_card()` 过滤，只保留 `card_type == 9` 的微博卡片；
- 搜索到帖子后立即保存，随后尝试抓取评论和图片。

### 3.3 指定帖子模式

当 `CRAWLER_TYPE == "detail"` 时，进入 `get_specified_notes()`：

```python
async def get_specified_notes(self):
    semaphore = asyncio.Semaphore(config.MAX_CONCURRENCY_NUM)
    task_list = [
        self.get_note_info_task(note_id=note_id, semaphore=semaphore)

    video_details = await asyncio.gather(*task_list)
    for note_item in video_details:
        if note_item:
            await weibo_store.update_weibo_note(note_item)
```

每条微博详情通过 `get_note_info_task()` 并发抓取，抓取失败会被 `DataFetchError` 或 `KeyError` 捕获并打印日志。

## 4. API 请求封装：`client.py`

`WeiboClient` 封装了微博移动端接口请求，核心基址是：

```python
self._host = "https://m.weibo.cn"
```

### 4.1 通用请求

```python
async def request(self, method, url, **kwargs):
    async with httpx.AsyncClient(proxy=self.proxy) as client:
        response = await client.request(method, url, timeout=self.timeout, **kwargs)

    data = response.json()
    ok_code = data.get("ok")
    if ok_code == 0:
        raise DataFetchError(data.get("msg", "response error"))
    elif ok_code != 1:
        raise DataFetchError(data.get("msg", "unknown error"))
    else:
        return data.get("data", {})
```

所有接口返回若 `ok == 1`，则返回 `data` 字段；否则抛错。

### 4.2 搜索接口

```python
async def get_note_by_keyword(
    self,
    keyword: str,
    page: int = 1,
    search_type: SearchType = SearchType.DEFAULT,
) -> Dict:
    uri = "/api/container/getIndex"
    containerid = f"100103type={search_type.value}&q={keyword}"
    params = {
        "containerid": containerid,
        "page_type": "searchall",
        "page": page,
    }
    return await self.get(uri, params)
```

这里的关键是构造 `containerid`，微博搜索结果的分类类型由 `search_type.value` 决定。

### 4.3 评论接口

```python
async def get_note_comments(self, mid_id: str, max_id: int, max_id_type: int = 0) -> Dict:
    uri = "/comments/hotflow"
    params = {
        "id": mid_id,
        "mid": mid_id,
        "max_id_type": max_id_type,
    }
    if max_id > 0:
        params.update({"max_id": max_id})
    referer_url = f"https://m.weibo.cn/detail/{mid_id}"
    headers = copy.copy(self.headers)
    headers["Referer"] = referer_url
    return await self.get(uri, params, headers=headers)
```

评论翻页通过 `max_id` 和 `max_id_type` 控制。

### 4.4 详情接口

```python
async def get_note_info_by_id(self, note_id: str) -> Dict:
    url = f"{self._host}/detail/{note_id}"
    async with httpx.AsyncClient(proxy=self.proxy) as client:
        response = await client.request("GET", url, timeout=self.timeout, headers=self.headers)
        if response.status_code != 200:
            raise DataFetchError(f"get weibo detail err: {response.text}")
        match = re.search(r'var \$render_data = (\[.*?\])\[0\]', response.text, re.DOTALL)
        if match:
            render_data_json = match.group(1)
            render_data_dict = json.loads(render_data_json)
            note_detail = render_data_dict[0].get("status")
            return {"mblog": note_detail}
```

微博详情页会把帖子 JSON 放在 `$render_data` 变量里，因此这里不是调用 JSON API，而是从 HTML 中正则提取。

```python
    container_id: str,

    callback: Optional[Callable] = None,

    result = []
    notes_has_more = True
    since_id = ""
    crawler_total_count = 0
    while notes_has_more:
        notes_res = await self.get_notes_by_creator(creator_id, container_id, since_id)
        since_id = notes_res.get("cardlistInfo", {}).get("since_id", "0")

            await callback(notes)

        result.extend(notes)

        notes_has_more = notes_res.get("cardlistInfo", {}).get("total", 0) > crawler_total_count
    return result
```

## 5. 登录逻辑：`login.py`

`WeiboLogin` 负责三种登录方式：

- `qrcode`
- `phone`

### 5.1 二维码登录

```python
async def login_by_qrcode(self):
    await self.context_page.goto(self.weibo_sso_login_url)
    qrcode_img_selector = "xpath=//img[@class='w-full h-full']"
    base64_qrcode_img = await utils.find_login_qrcode(
        self.context_page,
        selector=qrcode_img_selector
    )
    partial_show_qrcode = functools.partial(utils.show_qrcode, base64_qrcode_img)
    asyncio.get_running_loop().run_in_executor(executor=None, func=partial_show_qrcode)

    current_cookie = await self.browser_context.cookies()
    _, cookie_dict = utils.convert_cookies(current_cookie)
    no_logged_in_session = cookie_dict.get("WBPSESS")

    try:
        await self.check_login_state(no_logged_in_session)
    except RetryError:
        sys.exit()
```

登录状态检查用 `tenacity` 重试，最长 600 次，每次间隔 1 秒：

```python
@retry(stop=stop_after_attempt(600), wait=wait_fixed(1), retry=retry_if_result(lambda value: value is False))
async def check_login_state(self, no_logged_in_session: str) -> bool:
    current_cookie = await self.browser_context.cookies()
    _, cookie_dict = utils.convert_cookies(current_cookie)
    if cookie_dict.get("SSOLoginState"):
        return True
    if cookie_dict.get("WBPSESS") != no_logged_in_session:
        return True
    return False
```

只要 `SSOLoginState` 出现，或者 `WBPSESS` 发生变化，就认为登录成功。

## 6. 辅助逻辑：`help.py` 与 `exception.py`

### 6.1 搜索结果过滤

`help.py` 只有一个关键函数：

```python
def filter_search_result_card(card_list: List[Dict]) -> List[Dict]:
    note_list: List[Dict] = []
    for card_item in card_list:
        if card_item.get("card_type") == 9:
            note_list.append(card_item)
        if len(card_item.get("card_group", [])) > 0:
            card_group = card_item.get("card_group")
            for card_group_item in card_group:
                if card_group_item.get("card_type") == 9:
                    note_list.append(card_group_item)
    return note_list
```

微博搜索返回的 `cards` 可能混有推荐卡片、用户卡片等，这里只保留 `card_type == 9` 的微博内容卡片。

`DataFetchError` 会用于 API 异常、详情页解析失败等场景；`IPBlockError` 用于限流提示。

### 7.4 数据库存储实现

`_store_impl.py` 中的 `WeiboDbStoreImplement` 使用 SQLAlchemy 异步会话做 upsert：

```python
async def store_content(self, content_item: Dict):
    note_id = content_item.get("note_id")
    async with get_session() as session:
        stmt = select(WeiboNote).where(WeiboNote.note_id == note_id)
        res = await session.execute(stmt)
        db_note = res.scalar_one_or_none()
        if db_note:
            db_note.last_modify_ts = utils.get_current_timestamp()
            for key, value in content_item.items():
                if hasattr(db_note, key):
                    setattr(db_note, key, value)
        else:
            content_item["add_ts"] = utils.get_current_timestamp()
            content_item["last_modify_ts"] = utils.get_current_timestamp()
            db_note = WeiboNote(**content_item)
            session.add(db_note)
        await session.commit()
```

评论和创作者信息也采用类似的 upsert 逻辑。

## 10. 微博爬虫关键设计点

| 设计点 | 说明 |
|--------|------|
| 移动端优先 | 主要使用 `m.weibo.cn` 接口，而不是 PC 端 `weibo.com` |
| 登录态复用 | 通过 Playwright persistent context 或 CDP 复用浏览器环境 |
| Cookie 同步 | 浏览器登录后同步到 `WeiboClient`，API 请求继续用同一会话 |
| 搜索分页固定 10 | 微博搜索接口单页固定 10 条，因此 `CRAWLER_MAX_NOTES_COUNT` 建议是 10 的倍数 |
| 请求限速 | 翻页、评论、图片抓取后都固定 sleep，降低封号风险 |
| 详情页 HTML 解析 | 详情数据从 HTML 中 `$render_data` 正则提取，而非调用结构化 JSON 接口 |
| 评论递归 | 支持热门评论和二级子评论抓取，但需要开启 `ENABLE_GET_SUB_COMMENTS` |
| 存储多后端 | 支持 CSV、DB、JSON、SQLite、PostgreSQL 多后端存储 |
| upsert 存储 | 数据库存储会先查主键，存在则更新，不存在则插入 |

## 11. 常见问题

### 11.1 登录失败或超时

- 在 `base_config.py` 设置：
  ```python
  HEADLESS = False
  ```
- 手动扫码时检查是否打开了正确的二维码页面；
- 删除 `browser_data/` 后重新登录以清掉脏 Cookie。

### 11.2 搜索结果为空

- 检查 `WEIBO_SEARCH_TYPE` 是否为合法值；
- 检查 `KEYWORDS` 是否为空；
- 确认账号没有被限制搜索权限。

### 11.3 详情页解析失败

`get_note_info_by_id()` 依赖 HTML 中的：

```javascript
var $render_data = [...][0];
```

若微博改版导致该变量名变化，需要同步修改正则表达式。

### 11.4 评论抓取为空

- 确认开启了 `ENABLE_GET_COMMENTS = True`；
- 部分微博关闭评论或设置了仅粉丝可见；
- 检查是否触发频控导致接口返回空数据或错误。
